How it works

  1. The buttons open the tool with the full prompt already in the composer. The first thing it does is ask for your target company, role, level and language.
  2. It researches that company's current coding round on the web, proposes a scenario and a file tree, and waits for one “yes”.
  3. It builds the challenge, proves every target with reference solutions, deletes the proofs, audits for leaks, runs every command and pastes the output.
  4. You get an Instruction.md, the code, the data, the tests and a benchmark. Set a 60-minute timer and start.

The build needs an agent with a shell and web search (Claude Code, Codex, Cursor and similar). A chat tool will do the intake and the research, then tell you where it needs to hand off. For a coding agent, copy the prompt and paste it as the first message in an empty directory.
